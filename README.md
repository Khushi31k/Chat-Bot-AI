# 💜 ELLA – AI Personal Companion

> **An AI companion that remembers, plans, and grows with you.**

ELLA is a full-stack AI-powered productivity platform that combines intelligent conversations, journaling, habit tracking, goal management, calendar planning, mood tracking, meditation, and long-term memory into one seamless experience.

Unlike traditional chatbots or productivity apps, ELLA learns from your interactions and provides personalized insights to help you stay organized, productive, and mindful.

## ⚡ Getting Started

Clone the repository

```bash
git clone https://github.com/Khushi31k/ELLA-AI-Personal-Companion.git
```

Navigate to the project

```bash
cd ELLA-AI-Personal-Companion
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
